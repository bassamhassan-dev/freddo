# Sprint 16 — رفع الصور على Cloudinary (شرح بالمصري)

## الهدف
توثيق المتطلبات 16 + قرار بسام: الأدمن يرفع صور البانرات من جهازه بدل ما
يلزق روابط. الصور بتتخزن على Cloudinary، وقاعدة البيانات بتخزن الرابط
والـ public ID بس — مفيش ولا بايت صور على السيرفر بتاعنا (المستند نفسه
بيقول كده).

## اللي اتبنى

### الـ pipeline (سيرفر)
- مكتبتا `cloudinary` (الـ SDK الرسمي) و `multer` (قراءة الملفات المرفوعة
  في الذاكرة — الصورة مابتلمسش الهارد خالص).
- `POST /api/admin/uploads` (أدمن بس): خانة واحدة اسمها `image`، تحقق من
  النوع (JPG/PNG/WebP بس) والحجم (5MB كحد أقصى)، ورفع لفولدر `freddo`.
  بيرجع `imageUrl` (HTTPS) و `publicId`.
- `GET /api/admin/uploads/status`: بيقول للواجهة Cloudinary متظبط ولا
  لأ، عشان زرار الرفع ميظهرش وهو مش شغال.

### البوابة البيئية (env gate)
كله مربوط بـ 3 متغيرات: `CLOUDINARY_CLOUD_NAME` و `CLOUDINARY_API_KEY` و
`CLOUDINARY_API_SECRET` في `server/.env`. لو مش موجودين:
- الموقع شغال عادي بروابط الصور اليدوية (مفيش حاجة اتكسرت).
- زرار الرفع مخفي من لوحة الأدمن.
- لو حد نادى الـ endpoint بيرجع **503 CLOUDINARY_NOT_CONFIGURED** بشكل
  نضيف، مش crash.

### دورة حياة الصورة (المستند: «استبدال/حذف الصور يراعي المراجع»)
- الأدمن بيستبدل صورة بانر مرفوعة؟ الصورة القديمة **بتتمسح من Cloudinary**
  تلقائيًا عشان الأصول اليتيمة مابتتكومش.
- حذف بانر بيمسح صورته من Cloudinary برضه.
- المسح best-effort: لو Cloudinary وقع لحظتها، التعديل نفسه مابيفشلش —
  بنسجل ونكمل.

### الواجهة
فورم البانر فيه زرار اختيار ملف (بيظهر بس لما الرفع متظبط) + معاينة
مصغرة للصورة المختارة. بعد الرفع، الرابط والـ public ID بيتحطوا في الفورم
زي ما يكون اتلزقوا يدوي — الحفظ نفس المسار بالظبط.

## الاختبارات (3 جداد — المجموع 97/97 سيرفر)
1. الـ status بيبلغ «مش متظبط» من غير env vars.
2. الرفع من غير ظبط بيرجع 503 نظيفة (مش 500).
3. الرفع أدمن-بس (401 للضيف، 403 للعميل).
الرفع الفعلي بيتأكد يدويًا أول ما بيانات الحساب توصل (الخطوات تحت).

## توصيل بيانات الحساب (لما تجهز)
1. من Cloudinary Dashboard: انسخ Cloud Name و API Key و API Secret.
2. حطهم في `server/.env` في المتغيرات التلاتة اللي فوق (موجودين فاضيين في
   `.env.example`). ممنوع يتكتبوا في أي ملف يتكومّت.
3. شغّل `npm run dev`، افتح لوحة الأدمن → تاب البانرات → بانر جديد:
   زرار اختيار الملف هيكون ظاهر. ارفع صورة، احفظ، وافتح الصفحة الرئيسية —
   البانر لازم يظهر من رابط res.cloudinary.com.
4. استبدل الصورة واتأكد من Cloudinary Media Library إن القديمة اتمسحت.
