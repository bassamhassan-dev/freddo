# Sprint 18 — الهوية البصرية والهيرو (شرح بالمصري)

## الهدف
ملاحظات بسام بعد أول تشغيل محلي: صفحات الدخول/التسجيل محتاجة روح فريدو
واللوجو في نص الفورم، خانة تأكيد الباسورد في التسجيل، والصفحة الرئيسية
مفيهاش hero ظاهر. ومعاهم إصلاح فجوة توثيق: متغيرات الأدمن ماكانتش في
`.env.example`.

## اللي اتبنى

### الهيرو (الصفحة الرئيسية)
قسم hero ثابت بيظهر **دايمًا** — اللوجو المتوهج + بخار متحرك + الجملة
الترحيبية (اللي لسه قابلة للتعديل من CMS). سبب اختفائه عنده: البانرات
بتتخبى لما مفيش بانرات، وده كان مقصود؛ بس الهوية نفسها مينفعش تتخبى،
فاتفصلت في مكوّن خاص. بانرات تجريبية جاية في Sprint 19 مع صور المنيو.

### صفحات الدخول والتسجيل
- مكوّن `FreddoMark` واحد بيستخدم في التلات أماكن (هيرو + الدخول +
  التسجيل): كلمة FREDDO متوهجة بنبض بطيء وفوقها 3 خيوط بخار بتطلع.
- الأنيميشن CSS خالص (keyframes) — مفيش مكتبات، وبيتوقف تمامًا لأي حد
  مفعّل prefers-reduced-motion (إتاحة الوصول).
- خانة **تأكيد الباسورد** في التسجيل: تحقق تطابق على الكلاينت برسالة
  باللغتين، والسيرفر زي ما هو بيتحقق من قواعد الباسورد الحقيقية. الاختبار
  بيتأكد إن الـ API مابيتندهش أبدًا لما الاتنين مختلفين.

### توثيق البيئة
`.env.example` بقى فيه `ADMIN_EMAIL` و `ADMIN_PASSWORD` و `ADMIN_NAME`
فاضيين مع شرح إن حساب الأدمن بيتعمل **بس** من `npm run seed` بعد ملء
المتغيرات — دي كانت فجوة حقيقية سببت لخبطة.

## الاختبارات (المجموع: سيرفر 102/102، كلاينت 21/21)
- اختبار جديد: باسوردين مختلفين بيمنعوا الإرسال وبيظهروا الرسالة العربية
  من غير ما السيرفر يتنده.
- اختبار الـ smoke اتعدّل لأن كلمة FREDDO بقت في الهيدر + الهيرو.
- فحص بصري بالسكرينشوت: صفحة التسجيل والهيرو بالعربي RTL — شغالين صح.
