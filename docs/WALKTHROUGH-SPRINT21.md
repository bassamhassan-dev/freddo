# سبرينت ٢١: لمسات تفاعلية (UX polish)

## الفكرة
الموقع يحس إنه حي من غير ما نضيف مكتبة ولا ميزة جديدة - كل اللمسات CSS خالص، وبتتقفل تماماً لو المستخدم مفعّل prefers-reduced-motion.

## اللي اتعمل
1. **دخول ناعم لكل صفحة**: `<main>` بقى متغلّف بمكوّن بيعمل key على الـ pathname، فكل تنقّل بيعيد أنيميشن fade-up قصير (0.45s).
2. **كروت المنيو بتتفاعل**: hover بيرفع الكارت شوية لفوق وبيظهر حد العنبر، وصورة الصنف بتعمل zoom خفيف (scale 1.05 بنص ثانية).
3. **الأزرار بتحس بالضغط**: active:scale(0.97) على كل الأزرار من مكان واحد (مكوّن Button).
4. **البانرات بتلاطم بنعومة**: كل سلايد جديد بيدخل بـ fade-up، والنقط بتتلوّن بـ transition.
5. **تفاصيل الكروم نفسه**: التحديد (selection) بقى عنبري، والـ scrollbar رفيع غامق بيلمع عنبر مع الـ hover.
6. **إصلاح بانرات السيد**: شلنا النص المخبوز جوا الـ SVG (كان بيتكرر مع النص اللي فوق وبيتقص في العربي) - بقت خلفية زخرفية (تدرج + فنجان شفاف) والنص بييجي من HTML فوقها، فبيظهر صح بالعربي والإنجليزي.

## أرقام
- كلاينت ٢١/٢١ اختبار، بيلد الإنتاج شغال، مفيش أي dependency جديدة وحجم الباندل ثابت تقريباً (308KB).
- تحقق بصري بالسكرين شوت للرئيسية وحالة الـ hover.
