# Freddo - Sprint 0: شرح الهيكل والقرارات

> **تحديث Sprint 1.5:** الهيكل اتنضّم على قواعد `docs/CONVENTIONS.md`:
> الراوتس بقت جوه `src/features/` جنب باقي طبقات كل فيتشر. الشرح اللي تحت
> لسه صحيح، والمسارات الجديدة في الـ CONVENTIONS.


الملف ده شرح بالمصري لكل حاجة موجودة في الريبو لحد دلوقتي، وليه اتعملت كده.
اقراه كويس عشان تقدر تدافع عن كل سطر في أي إنترفيو.

## إيه اللي اتعمل في Sprint 0؟

لسه مفيش منيو ولا أوردرات ولا أي business logic. اللي اتعمل هو "الهيكل
العظمي": فولدرات منظمة، سيرفر شغال، فرونت إند شغال، دعم عربي/إنجليزي من أول
يوم، وتستات بتعدي. ده الأساس اللي كل sprint جاي هيبني عليه.

## ليه monorepo؟

المشروع كله في ريبو واحد فيه فولدر `server` وفولدر `client`. بنستخدم
ميزة npm workspaces اللي بتخلي `npm install` واحدة من الجذر تنزّل
dependencies الاتنين، وبتخلينا نشغّل أوامر على أي جزء بـ `npm run ... -w server`
أو `-w client`.

البديل كان ريبوهات منفصلة، بس لمشروع واحد بيتسلّم كقطعة واحدة، المونوريبو
أسهل: كوميت واحد ممكن يغيّر API والواجهة مع بعض، ومفيش مشاكل توافق نسخ بين
ريبوهين.

## السيرفر (server/)

- **Express** مش أي framework تاني: هو المعيار في سوق الشغل، وأغلب وظايف
  MERN هتسأل فيه.
- **ES modules** (`"type": "module"`) عشان نستخدم `import/export` زي
  الفرونت إند بالظبط - syntax واحد في المشروع كله.
- `src/app.js` فيه بناء تطبيق Express نفسه، و`src/index.js` هو اللي بيفتح
  البورت. الفصل ده مقصود: التستات بتعمل `import` للـ app من غير ما تفتح
  بورت حقيقي، وده pattern شائع اسمه "app/server separation".
- `src/routes/health.js` أول route: `GET /api/health` بيرجع
  `{ status: "ok" }`. اسمه health check، وأي deployment جاي هيحتاجه.
- `src/config/db.js` فيه فانكشن `connectDB()` جاهزة بـ Mongoose، بس
  **مش بتتنادى دلوقتي**. السيرفر شغال من غير قاعدة بيانات لحد Sprint 1 لما
  تظهر أول models. ده قصدًا: منضيفش dependency إلا لما نحتاجها فعلًا.
- `.env.example` فيه أسماء المتغيرات بقيم وهمية. القيم الحقيقية بتتحط في
  `.env` اللي متجاهل في `.gitignore` - **الأسرار مبتدخلش جيت أبدًا**.

## الفرونت إند (client/)

- **Vite** مش Create React App: أسرع بمراحل في التطوير، وCRA رسميًا بقى
  deprecated.
- **React 18** بـ functional components و hooks بس.

### ثنائية اللغة والاتجاه (أهم قرار في السبرينت ده)

الموقع عربي/إنجليزي من أول يوم، مش ترجمة هتتلزق في الآخر:

- `src/i18n/en.json` و `src/i18n/ar.json` فيهم نفس المفاتيح بالظبط، وفيه
  تست بيتأكد إن الملفين متطابقين في المفاتيح - لو نسيت تضيف ترجمة، التست
  هيقع.
- `src/i18n/index.js` فيه 3 حاجات:
  - `DEFAULT_LANG = 'ar'` لأن جمهور فريدو عربي أولًا.
  - `getDirection(lang)` بترجع `rtl` للعربي و`ltr` للإنجليزي. أي قرار
    اتجاه في المشروع بيعدي من الفانكشن دي بس.
  - `t(lang, key)` بترجع الترجمة، ولو المفتاح مش موجود في اللغة الحالية
    بترجع الإنجليزي كـ fallback.
- في `App.jsx` فيه `useEffect` بيحط `dir` و`lang` على عنصر `<html>`
  نفسه. ده مهم: لما الـ dir على مستوى الصفحة كلها، المتصفح بيقلب الـ layout
  والـ scrollbars والمحاذاة لوحده، بدل ما نعكس كل حاجة بإيدنا في CSS.

## التستات

- **السيرفر:** `node --test`، مكتبة التست المدمجة في Node نفسه - مفيش
  dependency زيادة. التست بيشغّل الـ app على بورت عشوائي (`listen(0)`) ويعمل
  fetch حقيقي للـ endpoints.
- **الفرونت إند:** Vitest + Testing Library. Vitest بيتكامل مع Vite طبيعي،
  وفيه smoke test بيتأكد إن الصفحة بتفتح عربي و`dir="rtl"`.
- `npm test` من الجذر بيشغّل تستات الاتنين ورا بعض.

## أوامر مهمة

```bash
npm install        # مرة واحدة بعد الكلون
npm run dev        # سيرفر + فرونت مع بعض
npm test           # كل التستات
npm run build      # build إنتاج للفرونت إند
```
