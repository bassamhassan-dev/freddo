# Freddo - Sprint 1: قاعدة البيانات، أول model، وأول API حقيقي

الملف ده شرح بالمصري لكل قرار اتاخد في Sprint 1، عشان تقدر تدافع عنه في أي
إنترفيو. اقره بعد WALKTHROUGH.md بتاع Sprint 0.

## إيه اللي اتعمل في Sprint 1؟

1. توصيل MongoDB بـ Mongoose (`connectDB`).
2. أول model: `MenuItem` بالعربي والإنجليزي مع بعض.
3. أول API حقيقي: `GET /api/menu` و `GET /api/menu/:slug`.
4. سكريبت seed بيملى منيو تجريبي.
5. الفرونت إند بقى Tailwind CSS + shadcn، وبيجيب المنيو من الـ API.
6. تستات لكل ده: 9 في السيرفر و7 في الفرونت إند، كلها خضرا.

## توصيل قاعدة البيانات (server/src/config/db.js)

- الـ URI بيتقري من البيئة بس (`MONGO_URI`، وبنقبل `MONGODB_URI` كمان لو
  حد كتبها كده). **ممنوع** يتحط في الكود أو يتبعت في شات - هو سر، ومكانه
  `server/.env` اللي متجاهل في `.gitignore`.
- في `index.js` بنعمل connect الأول وبعدين listen. ليه؟ لأن API المنيو
  من غير قاعدة بيانات ملوش لازمة، فالأصح إنه يقع بسرعة وبصوت عالي (fail
  fast) بدل ما يفضل يرد على طلبات بأخطاء. لو الاتصال فشل، بنطبع رسالة
  واضحة عربي/إنجليزي وبنقفل العملية بـ `process.exit(1)`.

## الـ Model (server/src/models/MenuItem.js)

الحقول جاية من مستند المتطلبات بتاعك (قسم 6.2)، بمعمولة bilingual من أول يوم:

- `localizedString`: أي نص بيتخزن `{ ar, en }` والاتنين required. مفيش
  صنف ينزل من غير لغة منهم - المنيو ثنائي اللغة بالتصميم، مش ترجمة
  هتتلزق بعدين.
- `slug`: معرّف unique صالح للينكات (`spanish-latte`). الـ API العام
  بيستخدمه بدل `_id` بتاع Mongo، عشان منكشفش تفاصيل داخلية واللينكات
  تبقى مقروءة.
- `category`: embedded في الصنف (`slug` + اسم باللغتين). المتطلبات عايزة
  categories يديرها الأدمن بصور وترتيب، وده هيبقى collection لوحده في
  sprint الأدمن والأصناف هتشاور عليه. لحد ما ده يحصل، الـ embedding بيخلي
  المنيو شغال من غير ما نبني أدوات أدمن قبل وقتها.
- `variants` و `addOns`: embedded زي ما المتطلبات بتقول بالظبط (6.3 و
  6.4) - المقاسات والإضافات مش بتتدار لوحدها، فمجموعة منفصلة كانت هتزود
  joins من غير فايدة.
- `images`: مصفوفة `{url, storageId?, alt}`. الـ `storageId` فاضي دلوقتي،
  جهز لما نرفع صور على تخزين حقيقي.
- `rating`: متوسط وعدد، ملخص بس (الريفيوهات نفسها feature جاية).
- `timestamps: true`: Mongoose بيضيف `createdAt` و `updatedAt` لوحده.
- index على `{ isAvailable, sortOrder }`: دي بالظبط الطريقة اللي المنيو
  العام بيتقري بيها، فالقراءة بتفضل سريعة لما الأصناف تكتر.
- `toPublicJSON()`: serializer صريح (المتطلبات 7.5). الـ API بيرجع الحقول
  واحد واحد، فأي حاجة تتضاف للـ schema بعدين - ملاحظات داخلية، تكلفة،
  وصفات الباريستا - مش هتتسرب للعملاء إلا لو حد ضافها هنا بقصد.

## الـ API (server/src/routes/menu.js)

- `GET /api/menu`: بيرجع الأصناف المتاحة بس. الفلترة بتحصل **في استعلام
  قاعدة البيانات نفسه** مش في الفرونت إند - صنف متقفل ميعرفش يوصل للعميل
  أصلًا. فيه `?category=slug` اختياري (6.7). الترتيب بـ `sortOrder`.
- `GET /api/menu/:slug`: صنف واحد لصفحة التفاصيل. بيرجع 404 برسالة
  عربي/إنجليزي لو الصنف مش موجود أو متقفل.
- شكل الخطأ ثابت في كل الـ API: `{ error: { code, message: {ar, en} } }`
  (شوف `middleware/errors.js`). الفرونت إند بيعرض الرسالة بلغة الواجهة
  وبيتصرف حسب الـ code. الأخطاء غير المتوقعة بترجع 500 برسالة عامة -
  التفاصيل الداخلية مبتتسربش للعميل.

## الـ Seed (server/src/seed/seed.js)

`npm run seed` بيحمل 11 صنف تجريبي (منهم واحد متقفل عمدًا عشان يثبت إن
الـ API بيخبي الأصناف المتقفلة). بيعمل upsert بالـ slug، يعني شغّله مليون
مرة من غير ما يعمل تكرار.

## التستات

السيرفر بيستخدم `mongodb-memory-server`: MongoDB حقيقي بينزل ويشتغل في
الذاكرة وقت التست بس. يعني بنجرب الـ schema والـ validation والاستعلامات
على قاعدة بيانات فعلية، من غير أي URI ومن غير ما نمس بيانات حد. التستات
بتغطي: إخفاء الأصناف المتقفلة، الترتيب، الفلترة بالتصنيف، شكل الـ DTO
(مفيش `_id` ولا `isAvailable` في الرد)، الـ 404، والـ validation.

## الفرونت إند: Tailwind + shadcn

- **Tailwind CSS v3**: utility classes بدل CSS مكتوب بالإيد. الـ config
  (`tailwind.config.js`) فيه ألوان فريدو كـ design tokens.
- **shadcn**: مكتبة مش بتتنزل من npm - أسلوبها إن الكومبوننتس بتتنسخ جوا
  مشروعك (`src/components/ui/`) وتبقى ملكك تعدلها. عندنا `Button` و
  `Card` و `Badge` و `Skeleton` مبنيين بالنمط ده (CVA للـ variants و
  `cn()` لدمج الكلاسات).
- **الألوان**: نفس هوية الـ mock المتفق عليها بالظبط - أسود بني `#0b0806`
  مع عنبري نيون `#ffb21a` وكريمي `#f6e7cf` - معمولة HSL في CSS variables
  (`src/index.css`) عشان تعديلات الشفافية زي `bg-primary/10` تشتغل.
- **الخطوط**: Cairo و Tajawal من Google Fonts، مع fallback للنظام لو مفيش
  نت.
- **RTL**: الـ `dir` على مستوى الصفحة كلها زي Sprint 0، واستخدمنا
  خصائص منطقية (`me-1` بدل `mr-1`) فالاتجاه بيقلب أوتوماتيك مع اللغة.
- **الأسعار**: `Intl.NumberFormat` بعملة الجنيه المصري - `٧٥ ج.م.` بالعربي
  و `EGP 75` بالإنجليزي.
- المنيو بيتجاب مرة واحدة من `/api/menu`، والفلترة بالتصنيف بتحصل فوري
  على الكلاينت (القايمة صغيرة؛ وفلتر الـ API جاهز لما تكبر). فيه حالات
  تحميل (skeletons)، وخطأ مع زرار إعادة، وفاضي.

## جرب بنفسك

```bash
npm install
npm run seed      # بيملى المنيو في قاعدة بياناتك
npm test          # 16 تست (9 سيرفر + 7 كلاينت)
npm run dev       # السيرفر على 5000 والفرونت على 5173
```

افتح http://localhost:5173 وشوف المنيو، وقلّب اللغة من الزرار.
